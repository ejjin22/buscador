Para el uso de este programa tiene la opción de entregar 1 o 2 parametros.
Si entrega solo uno, deberá entregar la cadeana que quiere que se busque en sus archivos, la carpeta será automaticamente seleccionada como la carpeta /home.
Si entrega dos, el primer argumento deberá ser la cadena a buscar, el segundo la carpeta en la que quiere buscarla.
